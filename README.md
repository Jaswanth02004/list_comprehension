# 🐍 Python List Comprehensions: Syntax & Examples

A hands-on Python script demonstrating how to write concise, readable list comprehensions for data transformation, filtering, and nested structures[cite: 4]. This is the second installment in a Python learning repository.

## 📌 Topics Covered

The script (`List Comprehension.py`) is broken down into commented sections for step-by-step practice[cite: 4]:

1. **Basic List Operations & `lambda` Comparison** – Applying expressions across iterables using `[expression for item in iterable]` and comparing the syntax against `map()` with `lambda`[cite: 4].
2. **Conditional Filtering** – Filtering elements using `if` conditions (e.g., isolating even numbers or values above a threshold)[cite: 4].
3. **Nested Loops & Tuple Generation** – Generating coordinate pairs `(i, j)` from nested `range()` iterations in a single line[cite: 4].
4. **Matrix & Nested List Flattening** – Converting a 2D matrix into a flat 1D list[cite: 4].
5. **`for` Loop vs. List Comprehension** – Key takeaways on when to use traditional multi-line loops (complex logic) versus single-line comprehensions (simple, direct operations)[cite: 4].
